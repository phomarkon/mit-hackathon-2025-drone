# Thermal Drone Footage Anomaly Detector

An application for anomaly detection in thermal drone footage for search and rescue operations. This prototype helps identify potential missing persons by detecting and prioritizing thermal anomalies and potential human shapes.

## Features (Primarily Dashboard)

-   **Interactive Dashboard**: User-friendly Streamlit interface (`dashboard.py`) for analyzing thermal images.
-   **Anomaly Detection**: Uses **PatchCore** deep learning models (ResNet18/ResNet50 backbones loaded from `.pth` files) to calculate anomaly scores and generate heatmaps (`dashboard.py`).
-   **Human Detection (Conditional)**:
    -   Uses **YOLOv8** (`yolov8n.pt`) for bounding box detection *if* the `ultralytics` library is installed (`dashboard.py`).
    -   Falls back to a **custom thermal blob detection** method (adaptive thresholding + contour filtering) if YOLO is unavailable (`dashboard.py`, `test_human_detection.py`).
-   **Batch Processing**: Supports analyzing image directories via `process_directory.py` (Note: Verify if it uses PatchCore like the dashboard or the simpler method from `anomaly_detector.py`).
-   **Prioritization System**: Ranks results based on anomaly score and human detection, highlighting high-priority cases.
-   **Visual Analysis**: Displays original images, anomaly heatmaps, and human detection bounding boxes.
-   **Detailed Reporting**: CSV, HTML, and JSON summary reports (likely generated by `process_directory.py`).
-   **Model Selection**: Allows choosing between ResNet18 (faster) and ResNet50 (more accurate) PatchCore backbones in the dashboard.

## Setup Instructions

### Prerequisites

-   Python 3.8+ installed
-   Git (for cloning the repository)

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  Create and activate a virtual environment (recommended):
    ```bash
    python -m venv venv
    # On Windows: venv\Scripts\activate
    # On macOS/Linux: source venv/bin/activate
    ```

3.  Install base dependencies:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Install YOLOv8 support (Optional but Recommended):**
    The `requirements.txt` file is missing the `ultralytics` library needed for YOLOv8 human detection. Install it manually:
    ```bash
    pip install ultralytics
    ```
    *(Without this, the dashboard will fall back to the less accurate thermal blob detection method).*

## Usage Guide (Dashboard)

1.  Launch the dashboard (`python run_dashboard.py`).
2.  Select the PatchCore model backbone (ResNet18/ResNet50) in the sidebar.
3.  Configure human detection settings (e.g., enable/disable, thresholds) if options are available.
4.  Upload one or more thermal drone images.
5.  View the prioritized results table/grid. High-priority items (high anomaly score or detected human) are highlighted.
6.  Select an image for detailed view: original, anomaly heatmap, human bounding boxes.
7.  Use the "Simulate Alert" button to test audio alerts (`alert.mp3`).

## Technical Details

-   **Anomaly Detection (Dashboard)**: PatchCore algorithm using features extracted from pre-trained ResNet-18/50 backbones. Models loaded from `outputs/patchcore_resnet*/patchcore_*.pth`. Implemented in `dashboard.py`.
-   **Anomaly Detection (Standalone Script)**: `anomaly_detector.py` uses a simpler fine-tuned ResNet18 classifier (Not PatchCore).
-   **Human Detection (Dashboard)**:
    1.  **YOLOv8**: Uses `ultralytics` library with `yolov8n.pt` model if library is present.
    2.  **Thermal Blob Detection**: Fallback method using OpenCV; performs adaptive thresholding on grayscale image and filters contours by area. Configurable sensitivity/area.
-   **Preprocessing**: Standard image normalization for ResNet models. CLAHE might be applied (check code). `dashboard.py` includes patches for Streamlit/PyTorch compatibility.
-   **Libraries**: PyTorch, Torchvision, Streamlit, OpenCV (cv2), NumPy, Pandas, Matplotlib, Ultralytics (optional).

## Troubleshooting

-   **YOLO Not Working**: Ensure you have installed `ultralytics` (`pip install ultralytics`). Check dashboard logs/warnings.
-   **Dependencies**: Verify all packages in `requirements.txt` (and `ultralytics`) are installed in the active virtual environment.
-   **Model Loading Errors**: Ensure `.pth` and `.pt` files exist at the expected paths relative to `dashboard.py`. Check permissions.
-   **PyTorch Version**: Built with `torch==2.1.0` / `torchvision==0.16.0`. Other versions might cause issues.
-   **CUDA**: GPU acceleration is used if `torch.cuda.is_available()` returns true; otherwise, CPU fallback. Ensure CUDA drivers and compatible PyTorch are installed for GPU usage.
-   **Memory**: High-resolution images or large batches might cause memory errors. Reduce image size or process fewer images.
-   **Detection Accuracy**:
    -   Anomaly scores depend on PatchCore model quality and threshold settings.
    -   YOLOv8 accuracy depends on the model size (`yolov8n.pt` is small/fast) and suitability for thermal images.
    -   Thermal blob detection is sensitive to `sensitivity` and `min/max_area` parameters and lighting/contrast.

## Limitations

-   PatchCore models may require fine-tuning on domain-specific thermal data for optimal performance.
-   YOLOv8 models pre-trained on visible light images might not perform optimally on thermal data without fine-tuning.
-   Thermal blob detection is prone to false positives from non-human hot objects.
-   The distinction between `anomaly_detector.py` and the dashboard's implementation is confusing. The dashboard appears more advanced.
